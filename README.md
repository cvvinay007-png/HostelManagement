# 🏨 Hostel Management System

A web-based Hostel Management System developed using PHP and MySQL to simplify hostel administration and management.

## 🌐 Live Demo

**[Click here to visit the Hostel Management System](https://vinay-hdb.infinityfreeapp.com)**

## 📌 About the Project

The Hostel Management System is designed to manage hostel-related information through a web application. It provides an interface for handling student records, hostel details, room information, allocations and payments.

## ✨ Features

- Student Management
- Hostel Management
- Room Management
- Room Allocation Management
- Payment Management
- Database Integration

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Hosting:** InfinityFree
- **Version Control:** Git and GitHub

## 📂 Project Structure

- `allocations/` – Allocation management
- `assets/` – CSS, JavaScript and other assets
- `config/` – Database configuration template
- `hostels/` – Hostel management
- `includes/` – Shared application files
- `payments/` – Payment management
- `rooms/` – Room management
- `students/` – Student management
